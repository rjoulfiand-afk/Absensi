MATERI FINAL: ARSITEKTUR MULTI-MENU, AUTHENTICATION FLOW, & ALUR CRUD MVC
====================================================================================================

[PENJELASAN ALUR LOGIN & REGISTER MENUJU DASHBOARD]
1. REGISTER: 
   Siswa isi form -> Submit via POST -> AuthController nangkap data -> AuthModel simpan ke tabel `users`.
2. LOGIN:
   Siswa isi Username & Password -> Submit POST -> AuthController ngecek ke AuthModel -> Jika Valid:
3. SESSION CREATION:
   AuthController membuat `$_SESSION['id_user']`. Ini adalah "Kunci Pas". Selama kunci ini ada, 
   user tidak akan ditendang ke halaman login.
4. REDIRECT:
   Sistem melempar user via `header("Location: index.php?page=dashboard")`.
5. GUARD (Satpam Halaman):
   Di baris paling atas `dashboard.php` (dan halaman menu lainnya), kita pasang kode:
   `if(!isset($_SESSION['id_user'])) { tendang ke login; }`

[PENJELASAN ALUR "REAL-TIME" CRUD MVC (Sangat Jelas & Bebas Error)]
Bagaimana data berpindah tanpa error? Ini rutenya:
1. VIEW (Form Tambah): User klik "Simpan". Form ngirim data (POST) ke `index.php?page=tambah_data`.
2. ROUTER (index.php): Menangkap kata `tambah_data` dan mengarahkannya ke `DataController->form_tambah()`.
3. CONTROLLER: Menangkap `$_POST['nama']` dll, lalu menyuruh `DataModel->insertData(...)`.
4. MODEL: Menjalankan perintah SQL `INSERT INTO...` ke Database.
5. CONTROLLER (Lagi): Setelah Model selesai, Controller langsung meredirect balik `header("Location: index.php?page=menu1&pesan=sukses")`.
6. VIEW (Tabel): Halaman me-refresh seketika, dan SweetAlert muncul menangkap parameter `?pesan=sukses`.

1. DATABASE: SKEMA DASAR
====================================================================================================
CREATE DATABASE db_sekolah_master;
USE db_sekolah_master;

-- TABEL AUTH
CREATE TABLE users (
    id_user INT AUTO_INCREMENT PRIMARY KEY,
    nama_lengkap VARCHAR(100) NOT NULL,
    username VARCHAR(50) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL
);

-- TABEL MENU 1 (Contoh: Data Siswa)
CREATE TABLE data_siswa (
    id_siswa INT AUTO_INCREMENT PRIMARY KEY,
    nama VARCHAR(100) NOT NULL,
    kelas VARCHAR(50) NOT NULL
);

-- TABEL MENU 2 (Contoh: Data Guru)
CREATE TABLE data_guru (
    id_guru INT AUTO_INCREMENT PRIMARY KEY,
    nama_guru VARCHAR(100) NOT NULL,
    mata_pelajaran VARCHAR(100) NOT NULL
);

2. JANTUNG APLIKASI: ROUTER (index.php) - TARUH DI LUAR FOLDER
====================================================================================================
Di sinilah lu mendaftarkan ke-4 menu (atau lebih) yang lu mau.

<?php
session_start();
require_once 'config/database.php';
require_once 'controllers/AuthController.php';
require_once 'controllers/MenuSatuController.php';
// require_once 'controllers/MenuDuaController.php'; (Kalau udah lu bikin)

$auth = new AuthController($koneksi);
$menu1 = new MenuSatuController($koneksi);

// Parameter penentu halaman
$page = isset($_GET['page']) ?$_GET['page'] : '';

switch ($page) {
    // --- AREA AUTH ---
    case 'login': $auth->login(); break;
    case 'register': $auth->register(); break;
    case 'logout': $auth->logout(); break;

    // --- MENU 0: DASHBOARD UTAMA ---
    case 'dashboard':
        if(!isset($_SESSION['id_user'])) { header("Location: index.php"); exit; }
        require_once 'views/dashboard.php'; 
        break;

    // --- MENU 1: KELOLA SISWA ---
    case 'menu1':
        if(!isset($_SESSION['id_user'])) { header("Location: index.php"); exit; }
        $menu1->index(); 
        break;
    case 'tambah_menu1':
        $menu1->tambah(); break;
    
    // --- MENU 2, MENU 3, MENU 4 ---
    // Tinggal lu tambahin case-case baru di sini sesuai nama menu dan controllernya!

    // --- DEFAULT ROOT ---
    default:
        // Jika sudah login, paksa ke dashboard. Jika belum, lempar ke login.
        if(isset($_SESSION['id_user'])) { header("Location: index.php?page=dashboard"); exit; }
        $auth->login(); 
        break;
}
?>

🔥 PANDUAN SUPER JELAS: Cara Menambah Menu ke-4, ke-5, dan Seterusnya
Katakanlah lu disuruh bikin menu baru: "Data SPP". Gimana alurnya dari nol? Ikuti 5 langkah pasti ini:

Langkah 1: Bikin Tabel di Database
Buka phpMyAdmin, bikin tabel baru data_spp (id, nama_siswa, bulan, jumlah).

Langkah 2: Daftarin di Navbar (views/layout/navbar.php)
Tambahin kode HTML <li> baru di dalam list menu lu:

HTML
<li class="nav-item">
    <a class="nav-link <?php echo ($_GET['page'] == 'data_spp') ? 'active fw-bold' : ''; ?>" href="index.php?page=data_spp">Data SPP</a>
</li>
Hasilnya: Tombol "Data SPP" sekarang muncul di bagian atas semua halaman! Tapi kalau diklik belum bisa, makanya lanjut ke Langkah 3.

Langkah 3: Daftarin Rutenya di Router (index.php)
Buka index.php, gulir ke bagian switch ($page), tambahin ini:

PHP
case 'data_spp':
    if(!isset($_SESSION['id_user'])) { header("Location: index.php"); exit; }
    // Asumsi lu udah bikin file controllernya
    require_once 'controllers/SppController.php';
    $spp = new SppController($koneksi);
    $spp->index(); 
    break;
Langkah 4: Bikin Model & Controller (models/SppModel.php & controllers/SppController.php)

Model: Isi dengan perintah SELECT * FROM data_spp, INSERT INTO data_spp, dll (Bisa nyontek kode Model CRUD dari materi-materi gw sebelumnya).

Controller: Tangkap datanya pakai $_POST, kirim ke model, dan atur require_once 'views/spp_tampil.php';.

Langkah 5: Bikin File Tampilannya (views/spp_tampil.php)
Bikin file HTML baru. Jangan lupa masukin kode magis ini di dalam tag <body> biar navbarnya muncul:

PHP
<?php include 'views/layout/navbar.php'; ?>
Lalu bikin tabel pakai Bootstrap di bawahnya!

Selesai cuy! Konsep pemisahan navbar.php dan penggunaan switch-case di index.php ini adalah Rahasia Arsitektur Web Skala Besar. Dengan cara ini, lu mau disuruh bikin 4 menu, 10 menu, atau 100 menu sekalipun, aplikasinya nggak akan error dan kodenya tetep rapi! Gass pelajari alurnya!
