Kalau besok lu disuruh bikin web dengan Dashboard Multi-Menu yang Super Lengkap, lu WAJIB pakai gabungan dari "Materi Universal" + "Materi Kerangka Multi-Menu" yang udah gw kasih sebelumnya.

Biar lu paham luar kepala (nggak cuma ngafal kode), gw kasih "Cara Cepat Paham MVC Multi-Menu" pakai analogi MALL:

index.php = Satpam Pintu Masuk. Semua user WAJIB lewat sini. Nggak bisa langsung ke toko. Satpam yang nentuin lu mau ke toko mana (pakai switch($_GET['page'])).

views/layout/navbar.php = Papan Petunjuk Jalan. Isinya daftar menu. Biar nggak capek bikin papan petunjuk di setiap toko, papannya dibikin 1 aja, terus ditempel di semua halaman pakai perintah include.

Controller = Pelayan Toko. Dia yang nanya "Lu mau ngapain?", terus dia yang nyuruh koki (Model) masak datanya.

Model = Koki Database. Kerjaannya cuma masak (SELECT, INSERT, UPDATE, DELETE).

View = Ruang Makan/Tampilan Layar. Isinya murni HTML & Bootstrap.

💡 Cara Pintar & Cepat (The Hacker Way) buat Ujian Besok
Kalau lu sadar dari kode di atas, gw pakai trik Single-File Layout.
Artinya, lu nggak perlu misah-misahin file sidebar.php, topbar.php, dan footer.php. Semuanya disatukan di satu file views/dashboard_admin.php.

Terus, gimana cara halamannya berubah-ubah pas menunya diklik?
Lihat baris kode ini di atas:

PHP
<?php if($page == 'dashboard'): ?>
   // Tampilkan Kartu Selamat Datang
<?php endif; ?>

<?php if($page == 'data_barang'): ?>
   // Tampilkan Tabel CRUD Barang
<?php endif; ?>
Dengan trik rahasia ini:

Lu cukup bikin SATU FILE VIEW AJA (dashboard_admin.php).

Di index.php (Router), apapun menu yang diklik, lu arahin require_once-nya ke views/dashboard_admin.php terus menerus.

Tampilan konten yang ada di dalam kotak otomatis terganti sendiri berkat perintah if($page == '...').

Cek settingan Router index.php nya buat trik ini:

PHP
<?php
// ... settingan koneksi dan controller ...
$page = isset($_GET['page']) ? $_GET['page'] : 'dashboard';

switch ($page) {
    case 'login': $auth->login(); break;
    case 'logout': $auth->logout(); break;

    // AJAIBNYA DI SINI: Semua menu manggil file View yang SAMA!
    case 'dashboard':
    case 'data_barang':
    case 'transaksi':
        // Cek login dulu
        if(!isset($_SESSION['id_user'])) { header("Location: index.php"); exit; }
        
        // Panggil controllernya kalau butuh narik data dari database
        if($page == 'data_barang') {
            $data_banyak = $barangModel->getAll(); 
            // (Variabel $data_banyak ini nanti dipake nge-loop tabel di dalam IF view)
        }
        
        // Selalu panggil dashboard_admin.php
        require_once 'views/dashboard_admin.php'; 
        break;
}
?>
Kesimpulan Strategi
Kalau besok waktu ujian lu kepepet dan guru minta aplikasinya cepet jadi tapi fiturnya mau kelihatan kompleks:
Gunakan trik Single-File Layout ini. Lu copas template Dashboard Sidebar di atas, lalu masukkan tabel-tabel CRUD lu ke dalam blok if($page == '...'). Penguji akan melihat aplikasi lu layaknya software mahal, padahal rahasianya lu kelola dalam satu file interface yang rapi. Gaskeun!
