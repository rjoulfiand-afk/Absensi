LANGKAH 3: MODEL - MESIN DATABASE (models/AbsensiModel.php)
====================================================================
<?php
class AbsensiModel {
    private $db;
    public function __construct($koneksi) { $this->db =$koneksi; }

    // READ: Tampilkan data dari yang terbaru
    public function getAll() {
        return $this->db->query("SELECT * FROM rekap_hadir ORDER BY tanggal DESC, waktu_input DESC");
    }

    // READ 1 DATA: Untuk form Edit
    public function getById($id) {
        return $this->db->query("SELECT * FROM rekap_hadir WHERE id_absen = ".(int)$id)->fetch_assoc();
    }

    // CREATE: Simpan absen baru
    public function tambah($guru, $mapel,$siswa, $status,$tgl, $waktu) {$guru = mysqli_real_escape_string($this->db,$guru);
        $mapel = mysqli_real_escape_string($this->db, $mapel);$siswa = mysqli_real_escape_string($this->db,$siswa);
        
        return $this->db->query("INSERT INTO rekap_hadir (tanggal, waktu_input, nama_guru, mata_pelajaran, nama_siswa, status) 
                                 VALUES ('$tgl', '$waktu', '$guru', '$mapel', '$siswa', '$status')");
    }

    // UPDATE: Edit absen
    public function update($id, $guru,$mapel, $siswa,$status) {
        $id = (int)$id;
        $guru = mysqli_real_escape_string($this->db,$guru);
        $mapel = mysqli_real_escape_string($this->db, $mapel);$siswa = mysqli_real_escape_string($this->db,$siswa);
        
        return $this->db->query("UPDATE rekap_hadir SET nama_guru='$guru', mata_pelajaran='$mapel', 
                                 nama_siswa='$siswa', status='$status' WHERE id_absen=$id");
    }

    // DELETE: Hapus absen
    public function hapus($id) {
        return $this->db->query("DELETE FROM rekap_hadir WHERE id_absen = ".(int)$id);
    }
}
?>

LANGKAH 4: CONTROLLER - PENGATUR LALU LINTAS (controllers/AbsensiController.php)
====================================================================
<?php
require_once 'models/AbsensiModel.php';

class AbsensiController {
    private $model;
    public function __construct($koneksi) { $this->model = new AbsensiModel($koneksi); }

    // Halaman Utama Dashboard
    public function index() {
        $data_absen =$this->model->getAll();
        require_once 'views/dashboard.php';
    }

    // Proses Tambah Data
    public function form_tambah() {
        if ($_SERVER['REQUEST_METHOD'] == 'POST') {$tgl_sekarang = date('Y-m-d');
            $waktu_sekarang = date('H:i:s'); // Rekam jam persis pas disubmit$this->model->tambah($_POST['guru'],$_POST['mapel'], $_POST['siswa'],$_POST['status'], $tgl_sekarang,$waktu_sekarang);
            header("Location: index.php?pesan=tambah"); exit;
        }
        require_once 'views/tambah_absen.php';
    }

    // Proses Edit Data
    public function form_edit() {
        if ($_SERVER['REQUEST_METHOD'] == 'POST') {
            $this->model->update($_POST['id'], $_POST['guru'],$_POST['mapel'], $_POST['siswa'],$_POST['status']);
            header("Location: index.php?pesan=edit"); exit;
        } else {
            $data_edit = $this->model->getById($_GET['id']);
            require_once 'views/edit_absen.php';
        }
    }

    // Proses Hapus Data
    public function aksi_hapus() {
        if(isset($_GET['id'])) $this->model->hapus($_GET['id']);
        header("Location: index.php?pesan=hapus"); exit;
    }
}
?>

LANGKAH 6: ROUTER PUSAT TANPA LOGIN (index.php)
====================================================================
Taruh file ini di folder utama `app_absen`. Sangat simpel karena nggak perlu ngurus Session Auth.

<?php
require_once 'config/database.php';
require_once 'controllers/AbsensiController.php';

$absen = new AbsensiController($koneksi);

// Router nangkap URL. Kalau kosong, otomatis ke 'dashboard'
$page = isset($_GET['page']) ?$_GET['page'] : 'dashboard';

switch ($page) {
    case 'tambah':
        $absen->form_tambah();
        break;
    
    case 'edit':
        $absen->form_edit();
        break;
    
    case 'hapus':
        $absen->aksi_hapus();
        break;

    case 'dashboard':
    default:
        $absen->index();
        break;
}
?>
====================================================================
Penjelasan Cepat Alur Tanpa Login:
Gak Ada Hambatan: User buka localhost/app_absen/index.php, switch case di index.php langsung nembak ke default atau dashboard, lalu manggil $absen->index().

Controller Membaca Data: Controller ngambil semua data absensi dari Model (getAll()) lalu ngirim data itu ke file views/dashboard.php.

Jam Hidup di Dashboard: Di dalam views/dashboard.php, ada <script> JavaScript bernama jalankanJam(). Fungsi ini nggak butuh koneksi server lagi buat berdetak, dia ngambil waktu lokal dari laptop/PC saat web dibuka dan di-update setiap 1000 milidetik (setInterval).

CRUD Mulus: Kalau lu klik edit, form otomatis mendeteksi status H/I/S/A sebelumnya pakai logika if($data_edit['status'] == 'H') echo 'selected';. Begitu disimpan, langsung terlempar balik ke Dashboard dengan SweetAlert keren.
